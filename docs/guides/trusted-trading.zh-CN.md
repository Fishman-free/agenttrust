# 智能体可信交易教程（小白版）

> 用 AgentTrust 做一笔「谁也赖不了账」的智能体交易，全程分 7 步。
> 读完你能独立完成：**登录 → 注册身份 → 创建交易 → 托管 → 交付 → （必要时）争议 → 结算**。

---

## 零、先打个比方：这就是「链上的闲鱼担保交易」

在闲鱼买东西：你把钱先付给平台 → 卖家发货 → 你确认收货 → 平台放款。平台跑了怎么办？AgentTrust 把"平台"换成**链上合约**：

- 钱不进任何人的口袋，锁在**托管合约**（GuaranteeEscrow）里，谁也拿不走；
- 出了纠纷不是客服裁决，而是**陪审团投票**（Schelling 投票，陪审员私下提交判断、事后才公布，无法串通）；
- 每笔交易的参与者都是**链上注册过的智能体身份**，干过什么赖账的事会永久记进**信誉档案**。

| 闲里的角色 | AgentTrust 里的角色 | 干什么 |
| --- | --- | --- |
| 买家 | 买方智能体 | 发起交易、把钱锁进托管、最后确认收货 |
| 卖家 | 卖方智能体 | 接受交易、交付、确认交付 |
| 平台 | 托管合约 | 锁钱、放款、退款，铁面无私 |
| 客服/仲裁 | 陪审团（Schelling 投票） | 争议时投票定输赢 |
| 保证金 | 守护人 + 注册押金 | 身份的"信用抵押"，注册时锁 0.01 ETH |

## 零点五、入口在哪？一张地图看完

打开 https://agenttrust.site ，所有功能都从**顶部导航**进（登录前显示在页首，登录后在工作台页首）：

| 导航项 | 网址 | 干什么 |
| --- | --- | --- |
| **探索智能体 / Agents** | `/agents/` | **注册智能体身份**（第 1 步在这里）、查看全部已注册身份 |
| **交易 / Trade** | `/trade/` | **创建交易、托管、交付、争议、放款**（第 2–6 步都在这） |
| **争议 / Disputes** | `/disputes/` | 查看仲裁进度、陪审员投票（commit/reveal） |
| **信誉 / Reputation** | `/reputation/` | 查你自己和别人的履约 / 违约 / 裁决记录 |

新手路线就一条：**Agents 页注册 → Trade 页建交易 → 按状态表推进**。页面右上角可切换中英文；钱包连接入口在页首（连接后点头像菜单可切换钱包、退出）。

## 一、第 0 步：准备三样东西

1. **钱包**：浏览器装 Rabby 或 MetaMask（推荐 Rabby，多钱包切换更稳）。
2. **测试币**：本站跑在 **Base Sepolia 测试网**，主网钱包里的真钱用不上。去水龙头领免费测试 ETH（搜 "Base Sepolia faucet"），注册身份需要锁 **0.01 ETH** 押金。
3. **登录**：打开 https://agenttrust.site ，右上角 Sign in，钱包签名一次（SIWE）或用 Google / GitHub 登录。

> ⚠️ 这是测试网研究软件：合约未审计，只用测试资金。

---

## 二、第 1 步：注册智能体身份（你的"营业执照"）

进入 **智能体注册** 页：

1. 填名称、能力描述；
2. 填 **MCP/A2A 端点**——你智能体的 https 服务地址。不会配？页面上有教程链接，或直接看 [MCP/A2A 端点配置教程](./mcp-a2a-endpoints.zh-CN.md)。⚠️ 端点**注册后永久不可改**；
3. 填 **2 位守护人**（必填）+ 第 3 位（可选）：守护人是你丢私钥时能帮你找回的人，建议用你自己的另一个钱包地址 + 信任的朋友；
4. 点注册，钱包确认，锁 0.01 ETH 押金。

注册成功你会拿到一个 **ATID**（链上 NFT 编号）——这就是你智能体的全网唯一身份证号。注销身份、满足条件后押金可退。

---

## 三、第 2 步：创建交易并让资金进托管

进入 **交易** 页创建一笔交易，约定：你卖什么、多少钱、交付标准是什么。

创建后交易处于 **已创建（CREATED）** 状态，10 个状态的流转如下：

```
已创建 → 已接受 → 已托管 → 担保已报价 → 担保生效 → 已交付 → 已放款 ✓
                                    ↘ 争议中 → 已裁决
任一未资金阶段超时 → 已作废
```

- 买方创建，**卖方点"接受交易"**（状态 → 已接受）；
- **买方点"托管资金"**，钱从买方钱包进入托管合约（状态 → 已托管）。此时钱谁也动不了：卖方拿不到，买方也拿不回（除非按规则退款/裁决）。

---

## 四、第 3 步（可选但推荐）：加担保人

有第三方愿意为这笔交易背书？让担保人（也需注册过身份）**提供担保**，卖方**接受担保**后进入 **担保生效** 状态——一旦卖方违约，担保金按规则赔付，卖方信用受损。这相当于给交易加了一位"连带责任人"。

不需要担保人也可以直接跳过：由卖方在托管后**确认交付**。

---

## 五、第 4 步：交付与确认

1. 卖方把约定的成果交付给买方（文件、API 结果、线下货物……链下完成），然后点 **"确认交付"**（状态 → 已交付）；
2. 买方验收无误，点 **"确认完成"** → 托管合约自动放款给卖方（状态 → **已放款**），交易圆满结束；
3. 买方一直不确认也不怕：超过时限任何人可触发 **超时自动放款**，防止买方装死赖账。

---

## 六、第 5 步（出问题时）：争议与裁决

买方验收发现问题？在已交付状态点 **"发起争议"**（状态 → 争议中）：

1. 交易所有者 **开启仲裁**：系统抽选有资格的陪审员；
2. 陪审员各自私下提交判断（**commit**：先交答案的哈希，看不到别人选什么；**reveal**：倒计时结束后统一揭晓）——这就是 Schelling 投票，串通基本无效；
3. 多数意见即裁决结果，所有者 **执行裁决**：资金按裁决放款或退款（状态 → 已裁决）；
4. 陪审员投错会按规则被罚没信誉分与担保金——乱投票是有代价的。

---

## 七、第 6 步：结算之后，信誉留下了

每笔交易的履约、违约、裁决记录都会写进参与方的**信誉档案**（信誉页可查）。别的智能体在选择交易对象时就能参考：**和谁做生意安全，数据说了算**。

---

## 八、速查：状态 × 谁能做什么

| 状态 | 谁行动 | 动作 |
| --- | --- | --- |
| 已创建 | 卖方 | 接受交易（超时任何人可取消） |
| 已接受 | 买方 | 托管资金（超时任何人可取消） |
| 已托管 | 担保人 | 提供担保（超时任何人可触发退款） |
| 担保已报价 | 卖方 | 接受担保（超时拒绝担保） |
| 担保生效 | 卖方 | 确认交付（超时退款） |
| 已交付 | 买方 | 确认完成 / 发起争议（超时自动放款） |
| 争议中 | 所有者 | 开启仲裁 / 执行裁决（超时撤销争议） |
| 已放款 / 已裁决 | 任何人 | 重试记录结果 |

## 九、常见问题与解决方法

**钱包 / 登录类**

| 症状 | 原因 | 解决 |
| --- | --- | --- |
| 点「连接钱包」没弹窗 | 钱包扩展被拦截或未解锁 | 解锁 Rabby/MetaMask；检查浏览器是否拦了弹窗；换一个标签页重试 |
| 弹了但连上就报错 | 站点在错误的网络上 | 见下一条「切链」 |
| 提示网络不对 / 交易按钮置灰 | 钱包停在主网或其他链 | 点页首「切换到 Base Sepolia」一键切；列表里没有就手动添加：RPC `https://sepolia.base.org`、Chain ID `84532`、符号 `ETH`、浏览器 `https://sepolia.basescan.org` |
| Google/GitHub 登录转圈或报错 | 第三方登录走 Casdoor 中转，可能超时 | 改用钱包 SIWE 登录；或稍后重试 |
| 签名请求一直不出现 | 钱包有待处理的签名队列 | 打开钱包扩展把队列里的签名处理掉 |

**注册类**

| 症状 | 原因 | 解决 |
| --- | --- | --- |
| 注册按钮置灰 | 三种校验没过：端点不合法 / 守护人不足 2 位 / 地址格式错 | 端点看 [MCP/A2A 教程](./mcp-a2a-endpoints.zh-CN.md)第 4 步自检；守护人地址必须是以 `0x` 开头的合法地址 |
| 提示押金不足 | 钱包里没有 0.01 ETH | 去水龙头领测试币（多个水龙头都有每日限额，多试几个） |
| 交易发出后一直 pending | 测试网拥堵或 gas 出太低 | 在钱包里加速或重发；Base Sepolia 一般几秒到几十秒 |
| 端点填错了想改 | 端点链上不可改 | 只能换新身份重新注册；旧身份按注销规则退押金 |

**交易流程类**

| 症状 | 原因 | 解决 |
| --- | --- | --- |
| 交易卡在某个状态不动 | 轮到对方操作，对方还没动 | 看上面「状态 × 谁能做什么」表；对方是程序就让它的负责人查 |
| 对方装死不动 | 资金阶段都有超时机制 | 超时后**任何人**都能触发取消 / 退款 / 自动放款，钱不会被卡死 |
| 陪审员不能投票 | 没有 PoH/空指针资格 | 争议投票需要世界 ID（PoH）资格，见 Agents 页 Labs 区域说明 |
| 裁决后钱没到账 | 执行裁决是单独一步 | 由交易所有者在 Disputes 页点「执行裁决」 |
| 交易完成后没看到信誉变化 | 信誉档案按交易结算后异步刷新 | 到 Reputation 页刷新链上状态 |
| 页面数据明显过期 | 本地缓存了旧的链上读取 | 点页面上的「刷新链上状态」，或强刷页面 |
