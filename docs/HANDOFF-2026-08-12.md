## 3. 已合入 main 的 4 个修复（PR #2，merge `aa109d3`）

### 3.1 `e77177d` — CI coverage 用 `--ir-minimum`

- 文件：`.github/workflows/ci.yml`
- 现象：`forge coverage` 报 `Stack too deep / headStart`（Foundry 为准确统计临时关 optimizer + viaIR）。
- 修复：`forge coverage` → `forge coverage --ir-minimum`（本地复现并验证通过，Total 94.27%）。
- 验证：本地 `forge test` 94 passed；CI Contracts job 成功。

### 3.2 `035ee11` — `deploy.sh` 移除 busybox 不支持的 `{40}` 区间量词

- 文件：`contracts/scripts/deploy.sh`
- 现象：`extract_named_addresses` 用 `[0-9a-fA-F]{40}`，busybox awk 不支持 `{n}` 区间量词（08-11 的 `f9b3354` 只修了 `{64}`，漏了 `{40}`）。
- 修复：改写为 `index($0,"\"contractAddress\"") && match($0, /0x[0-9a-fA-F]+/)`，与 `{64}` 修复同思路。
- 验证：对真实 `broadcast/.../run-latest.json` 用新旧逻辑对比，输出一致；本地完整 Anvil 部署跑通。

### 3.3 `e5a8f35` — `deploy.sh` cwd 推导回退 WORKDIR

- 文件：`contracts/scripts/deploy.sh`
- 现象：脚本用 `$0` 推导 `CONTRACTS_DIR`，但 Docker setup 的 ENTRYPOINT 把脚本 COPY 到 `/usr/local/bin/agenttrust-deploy.sh`，导致 `cd` 到 `/usr/local`（错误目录），`forge script script/Deploy.s.sol` 报 `contract source info format must be <path>:<name>`。
- 修复：`if [ ! -f "$CONTRACTS_DIR/script/Deploy.s.sol" ]; then CONTRACTS_DIR=$PWD; fi`（回退到 Dockerfile WORKDIR `/app/contracts`）。
- 验证：本地模拟 Docker ENTRYPOINT（绝对路径调用 + cwd 在 contracts）完整部署成功。

### 3.4 `eb5aa65` — healthz 循环重试吸收 nginx 启动竞态

- 文件：`.github/workflows/ci.yml`（Docker job 的两处 healthz curl）
- 现象：`docker compose up` 返回后 frontend 刚 `Started`（nginx 仍在初始化），首个 curl 连接被 RST，`curl --retry-connrefused` 不重试 connection reset → `curl(56)`。
- 修复：改为 `for ... seq 1 60` 循环 `curl --fail /healthz` 直到 200（对任意非 200 都重试）。
- 验证：本地用延迟监听/立即 RST 的 mock 服务器验证循环逻辑；CI Docker job 通过。

## 6. 明确遗留事项 / 未完成

### 6.1 Node 20 弃用 warning（低优先级）

Deploy job 有 warning：`Node.js 20 is deprecated ... forced to run on Node.js 24`。涉及 `actions/checkout@v4`、`actions/configure-pages@v5`、`actions/deploy-pages@v4`、`actions/setup-node@v4`、`actions/upload-artifact@v4`。**不影响功能**，但后续可升级到兼容 Node 24 的 action 版本。

### 6.2 Base Sepolia 未部署（延续项）

`deployments/84532.json` 仍是 `undeployed`。未用真实私钥、未发布四合约、未链上 verification。页面写操作保持禁用，不得宣称生产可用。真实部署需单独授权，遵循 `contracts/demo/DEPLOY-BaseSepolia.md`。

### 6.3 尚未做生产审计（延续项）

无第三方合约审计、无真实资产风险、无生产监控/告警。Schelling 陪审员仍非随机抽选；commit secret 依赖浏览器本地存储。不能描述为 audited / production-ready / trustless final product。

### 6.4 Docker 完整业务流门禁（可选增强）

- Playwright 主 E2E 用原生 Anvil + 静态服务器；
- Docker job 独立验证 Compose、nginx、四合约、持久化复用、stale bytecode 拒绝；
- 二者未交叉：尚未让"完整注入钱包业务流"直接指向 Compose 内的 nginx/frontend。可加一个 Compose-targeted Playwright 模式。
