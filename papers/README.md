## 调研核心结论（速览）

1. **通信双栈已成标准**：MCP（智能体↔工具）+ A2A（智能体↔智能体）；身份/信誉/支付/问责的缺口由区块链层填补（ERC-8004 是主答案）
2. **纯声誉/纯声明不可靠**（提示注入/共谋/Sybil 实证），前沿共识：Proof（zk/TEE）+ Stake（质押惩罚）锚定高价值动作，声誉仅辅助
3. **"证明是智能体"无行业标准**（反向人证问题）——原创设计空间
4. **担保层主力机制**：escrow/HTLC + 质押 + 仲裁（Kleros/UMA），非保险；2025 已有 5 套工程实现（Internet Court 等）
5. **论文空白**：Schelling 点信誉社区 → 担保定价/争议裁决的闭环（无人在做）
